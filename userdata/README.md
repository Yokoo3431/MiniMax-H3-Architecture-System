# MiniMax H3 User Data Isolation Directory

> [!IMPORTANT]
> **User Data Protection**: All files inside `userdata/` are **strictly preserved** and will **NEVER be overwritten** by `launcher/Update_H3.bat` or git updates.

---

## Directory Structure

- `custom_workflows/`: Place your custom ComfyUI JSON workflows here.
- `custom_prompts/`: Custom prompt presets and text dictionary overrides.
- `custom_models/`: Additional custom LoRA weights or Fine-tuned checkpoints.
- `custom_configs/`: Private system environment overrides.
- `outputs/`: Generated MP4 video animation output files.
