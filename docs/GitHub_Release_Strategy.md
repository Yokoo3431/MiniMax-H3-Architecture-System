## Release Package Distribution Structure

For GitHub Releases, the repository can be downloaded directly as `MiniMax-H3-Architecture-System-v0.4.0.zip` containing:

```
MiniMax-H3-Architecture-System/
├── launcher/
│   ├── Install_H3.bat        # Double click to install
│   ├── Start_H3.bat          # Double click to run WebUI
│   ├── Update_H3.bat         # Double click to update
│   └── Diagnose_H3.bat       # Double click to diagnose
├── sync/                     # Lifecycle asset registry
├── configs/                  # System configs & workflow registry
├── hardware/                 # HAL auto-detection
├── scripts/                  # Downloader & task router
└── docs/                     # Full technical guides
```
