# MiniMax H3 Architecture System V0.7.3 图像驱动用户指南 (Image Workflow User Guide)

欢迎使用 MiniMax H3 图像驱动建筑 AI 视频生成平台 V0.7.3！本版本开启了从**建筑效果图图像分析**到**工作流与 Prompt 自动匹配生成**的全新体验。

---

## 1. 图像驱动使用流程

```
[1. 准备建筑效果图] ───> [2. 传入 Agent Orchestrator] ───> [3. 自动生成与渲染]
 (e.g. museum.png)        ("制作黄昏慢推进建筑动画")            - 图像特征分析
                                                                - 建筑意图推理
                                                                - 自动注入 ComfyUI 节点
```

---

## 2. CLI 快捷使用指令

直接在命令行运行图像驱动任务：

```powershell
python runtime/h3_orchestrator.py --image "userdata/custom_prompts/building.jpg" --task "把这个安藤风格混凝土美术馆效果图制作成黄昏推进动画"
```
