# MiniMax H3 Architecture System V0.7.2 用户使用指南 (User Workflow Guide)

欢迎使用 MiniMax H3 建筑 AI 视频生成平台 V0.7.2 版本！本版本实现了从自然语言意图提取到 ComfyUI 真实工作流自动注入的完全自动化。

---

## 1. 核心操作流程

```
[1. 提供效果图图片]  ──────>  [2. 输入自然语言描述]
 (e.g. building01.jpg)          ("把这个现代博物馆效果图制作成黄昏慢推进动画")
                                       │
                                       ▼
                              [3. 系统自动完成]
                               - 意图提取与建筑推理
                               - 匹配合适工作流 (3_night_transition)
                               - 加载视频预设 (day_night_transition)
                               - 生成 H3 优化 Prompt
                               - 自动注入 ComfyUI 节点 Payload
                                       │
                                       ▼
                              [4. ComfyUI 渲染生成视频]
```

---

## 2. CLI 快捷使用指令

直接在 PowerShell 或命令行中运行 Agent 调度器：

```powershell
python runtime/h3_orchestrator.py --image "userdata/custom_prompts/building.jpg" --task "把这个安藤风格混凝土美术馆效果图制作成黄昏推进动画"
```

