## 2. Infrastructure Freeze Directives

1. **Launcher & Deployment Layer Frozen**: `launcher/`, `installer/`, `updater/`, `release/`, `sync/` remain completely unchanged.
2. **UserData Isolation Enforced**: User custom workflows in `userdata/` remain strictly protected.
3. **ComfyUI Backend Decoupled**: ComfyUI strictly serves as a REST API video rendering backend.
