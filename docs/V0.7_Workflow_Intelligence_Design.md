## 1. Intent-Driven Workflow Schema Specification

In V0.7, workflows evolve from simple ComfyUI node graphs into **Semantic Architectural Workflows**.

```yaml
workflow:
  id: exterior_hero_animation
  name: Architecture Exterior Hero Animation
  category: Architecture Visualization
  intent: Premium client presentation rendering animation
  input_requirements:
    type: single_architectural_rendering
    min_resolution: [1280, 720]
  camera_preset: slow_cinematic_orbital_pan
  lighting_preset: golden_hour_twilight
  prompt_skill: architecture_prompt
  hardware_adapter:
    min_profile: H3_STANDARD
    recommended_profile: H3_PRO
  critic_evaluator: architecture_quality_check
```
