# Workflow Spec — 04_Drone_Aerial

## Purpose
Masterplan / campus / landscape overview from a controlled aerial perspective.

## Input
- 1 user-approved aerial rendering or masterplan image.

## Skill Mode
- `I2VA` (one first-frame image).

## Motion
- Controlled aerial reveal, small amplitude, slow speed.
- Prohibited: large orbit, 360° rotation, fast zoom.

## Reason
- Single-frame geometry limitation: a one-image I2VA source cannot reconstruct a
  large viewpoint sweep reliably.

## Preservation (highest priority)
- building massing, site/landscape context, proportions, perspective geometry.

- `NATIVE_GOLDEN_VALIDATED` — the verified Native Golden baseline
  (`04_Drone_Aerial_NATIVE_GOLDEN`), 1344×768 / 24fps / 107 frames, human review
  PASS.
