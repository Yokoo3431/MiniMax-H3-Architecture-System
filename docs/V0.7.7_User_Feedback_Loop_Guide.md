# MiniMax H3 Architecture System V0.7.7 闭环学习用户指南 (User Feedback Loop Guide)

欢迎使用 MiniMax H3 闭环自我改进建筑 AI 助手 V0.7.7！本版本首次具备了**自我生成 $\rightarrow$ 批评诊断 $\rightarrow$ 自动修正 $\rightarrow$ 二次生成 $\rightarrow$ 质量对比 $\rightarrow$ 经验记忆存盘**的完整闭环流程。

---

## 1. 1-Call 闭环自我改进 API

调用 `H3Orchestrator.run_feedback_loop()` 一键触发闭环优化：

```python
from runtime.h3_orchestrator import H3Orchestrator

orchestrator = H3Orchestrator()
result = orchestrator.run_feedback_loop(
    image="userdata/custom_prompts/building.jpg",
    task="安藤混凝土美术馆黄昏推进动画",
    max_iterations=2
)

print(f"迭代轮数: {result['iterations']}")
print(f"初始评分: {result['initial_score']}")
print(f"最终评分: {result['final_score']}")
print(f"质量提升: +{result['improvement']}")
print(f"成功策略: {result['successful_strategy']}")
```

---

## 2. CLI 闭环触发示例

在命令行中直接启动闭环优化任务：

```powershell
python runtime/h3_orchestrator.py --image "userdata/custom_prompts/building.jpg" --task "安藤混凝土美术馆黄昏推进动画"
```

输出的改善视频将自动存入 `userdata/outputs/`。
