# Studio UX2-P2 Entry Gate

Status: entry plan only. P2 implementation has not started.

P2 begins only after owner acceptance of the frozen P1 visual foundation.

## Allowed focus

- Make the existing Study selection and Recent Studies flow easier to scan.
- Clarify the existing create/open Study path.
- Preserve project and Study context across existing routes.
- Improve feedback for loading, empty, ready and completed states.
- Validate responsive behavior, keyboard access, focus visibility and readable
  contrast using the frozen P1 design tokens.

## Non-negotiable boundaries

- No timeline, editor, trimming, tracks, transitions, keyframes or effects.
- No media-library or asset-management system.
- No chat agent, plugin marketplace or model catalog.
- No second database, Job system, generation engine or workflow truth.
- No backend/API/schema change as part of the entry gate.

P2 must reuse the canonical Study, Job, Output and Engine contracts and remain
bounded by the simple flow: select/create Study, add reference, describe intent,
choose type, adjust primary parameters, generate and review output.
