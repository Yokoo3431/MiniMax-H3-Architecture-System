# MiniMax H3 Architecture System V0.7.8 建筑师用户指南 (Architect User Guide)

欢迎使用 MiniMax H3 建筑 AI 助手 V0.7.8 界面层！本版本成功将系统底层的图像理解、推理、记忆、Prompt、工作流与批评机制封装为面向建筑师的**极简工作流 (Architect Workflow)**。

---

## 1. 建筑师极简 API 调用

仅需传入 1~5 张建筑效果图及自然语言需求（例如：“把这个博物馆效果图制作成30秒黄昏建筑宣传动画”）：

```python
from runtime.h3_orchestrator import H3Orchestrator
from runtime.interface.architect_request import ArchitectRequest

orchestrator = H3Orchestrator()
request = ArchitectRequest(
    images=["userdata/custom_prompts/building.jpg"],
    task_description="把这个博物馆效果图制作成30秒黄昏建筑宣传动画",
    video_style="exterior_hero"
)

response = orchestrator.generate_from_architect_request(request)

print(f"状态: {response['status']}")
print(f"生成 Prompt: {response['generated_prompt']}")
print(f"匹配工作流: {response['selected_workflow']}")
print(f"生成的视频路径: {response['video_path']}")
print(f"批评得得分: {response['critic_score']}")
```

## 2. 预设系统与 Web UI

可以通过运行本地 Web UI 原型直接上传图片与生成：

```powershell
python interface/web/app.py
```

### 包含的建筑师预设 (`configs/user_video_presets.json`)：
1. **Exterior Hero Reveal** (`exterior_hero`)：黄昏视角下的主建筑物推进全景动画。
2. **Slow Pedestrian Walkthrough** (`slow_walkthrough`)：人行视角漫游中庭与庭院动画。
3. **Drone Aerial Orbit** (`drone_aerial`)：高空无人机环绕总平面与城市上下文动画。
4. **Day to Night Lighting Transition** (`day_night_transition`)：日落黄昏与 3500K 室内暖光渐变动画。
5. **Material & Texture Focus** (`material_detail`)：清水混凝土或木百叶建筑细部材质特写动画。
