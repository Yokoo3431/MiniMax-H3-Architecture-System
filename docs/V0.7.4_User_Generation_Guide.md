# MiniMax H3 Architecture System V0.7.4 视频生成用户指南 (User Generation Guide)

欢迎使用 MiniMax H3 建筑 AI 视频生成平台 V0.7.4！本版本标志着系统达成了首个生产可用的端到端里程碑。

---

## 1. 1-Call 视频生成流程

调用 `H3Orchestrator.generate_architecture_video()` 即可一步完成视频生成：

```python
from runtime.h3_orchestrator import H3Orchestrator

orchestrator = H3Orchestrator(comfy_url="http://127.0.0.1:8188")
result = orchestrator.generate_architecture_video(
    image="userdata/custom_prompts/building.jpg",
    task="把这个安藤风格混凝土美术馆效果图制作成黄昏推进动画"
)

print(f"生成的建筑视频路径: {result['video_path']}")
```

---

## 2. CLI 运行示例

在终端中一键启动：

```powershell
python runtime/h3_orchestrator.py --image "userdata/custom_prompts/building.jpg" --task "把这个安藤风格混凝土美术馆效果图制作成黄昏推进动画"
```

输出视频将自动保存至 `userdata/outputs/` 目录中。
