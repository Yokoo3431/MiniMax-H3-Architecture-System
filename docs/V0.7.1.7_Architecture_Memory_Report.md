## 2. Memory Schema & Database (`configs/architecture_memory.json`)

- **Project Info**: `memory_id`, `building_type`, `visualization_type`
- **Architectural Intent**: `design_language`, `spatial_character`, `material_expression`, `emotional_target`
- **Prompt Data**: `input_request`, `generated_prompt`, `negative_prompt`
- **Evaluation**: `quality_scores`, `detected_issues`, `improvement_notes`

## 3. Semantic Memory Retrieval Logic (`skills/architecture_prompt/memory_retriever.py`)

- **`retrieve_similar_case()`**: Searches historical memory database matching building typology and material intent.
- **`suggest_prompt_strategy()`**: Recommends target camera trajectory, lighting environment, and motions to avoid.

Example output:
```json
{
  "recommended_camera": "slow architectural reveal",
  "recommended_light": "soft twilight dusk sky with 3500K warm interior glow",
  "avoid": "dramatic fast cinematic motion",
  "matched_memory_id": "mem_001"
}
```
