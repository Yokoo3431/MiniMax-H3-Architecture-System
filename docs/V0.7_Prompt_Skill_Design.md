## 1. Architectural Intent Schema Specification

When an AI Agent receives natural language architectural requirements, the **Prompt Skill Engine** converts raw text into a structured `ArchitecturalIntentSchema`:

### Input Natural Language Example
> *"把这个建筑效果图做成黄昏环绕动画，保持建筑几何不变，增加室内暖光，镜头慢慢推进"*

### Generated Intent Schema JSON
```json
{
  "schema_version": "1.0.0",
  "intent_type": "architectural_visualization",
  "building_type": "modern_museum_facade",
  "camera_motion": "slow_orbital_pan_and_push",
  "lighting_environment": "golden_hour_twilight_warm_interior_glow",
  "artistic_style": "photorealistic_architectural_cinematic",
  "geometry_constraint": "preserve_structural_integrity",
  "temporal_elements": ["dusk_transition", "soft_breeze_vegetation"]
}
```

## 2. Directory & Module Design (`skills/architecture_prompt/`)

```
skills/architecture_prompt/
├── SKILL.md                          # Skill instruction document for Agents
├── prompt_parser.py                  # Converts text -> ArchitecturalIntentSchema
├── architecture_dictionary.py        # Professional architectural terms & vocabulary
├── h3_prompt_template.py             # Formats positive prompts tailored to MiniMax H3 DiT
├── negative_prompt_library.py        # Architectural artifact prevention negative prompts
└── style_adapter.py                  # Villa, skyscraper, museum, resort style presets
```

## 4. Architectural Negative Prompt Library Specification

Prevents common AI architectural video generation artifacts:
```
warped facade, melted columns, flickering glass panels, floating structural elements, unstable geometry, distorted window frames, low resolution textures, temporal jittering, blur
```
