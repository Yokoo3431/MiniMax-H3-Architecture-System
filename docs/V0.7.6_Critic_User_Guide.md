# MiniMax H3 Architecture System V0.7.6 建筑批评用户指南 (Critic User Guide)

欢迎使用 MiniMax H3 建筑 AI 视频生成与批评评估系统 V0.7.6！本版本首次引入了面向生产的**建筑批评闭环分析与反馈机制**。

---

## 1. 批评分析 API 使用示例

调用 `H3Orchestrator.critic_generation_result()` 对生成的建筑视频进行五维评估：

```python
from runtime.h3_orchestrator import H3Orchestrator

orchestrator = H3Orchestrator()
result = orchestrator.critic_generation_result(
    video_path="userdata/outputs/3_night_transition_output.mp4",
    original_image="userdata/custom_prompts/building.jpg",
    task="把这个安藤风格混凝土美术馆效果图制作成黄昏推进动画"
)

print(f"综合评分: {result['overall_score']}")
print(f"失败诊断: {result['issues']}")
print(f"修正建议: {result['recommendations']}")
```
